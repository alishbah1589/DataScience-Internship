# Iris Dataset Analysis

## Project Objective
The objective of this project is to perform Exploratory Data Analysis (EDA) on the Iris dataset using Python.

## Tools & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Tasks Performed
- Data loading and inspection
- Dataset exploration
- Statistical summary
- Missing value analysis
- Scatter plot visualization
- Histogram visualization
- Box plot visualization
- Correlation heatmap
- Duplicate data handling
- Pairplot analysis

## Key Insights
- Petal length and petal width show a strong positive relationship.
- Setosa species forms a clearly separate cluster.
- Petal-related features are highly useful for classification.
- One duplicate record was identified and removed.

## Conclusion
The project successfully demonstrated how Exploratory Data Analysis helps in understanding data distributions, relationships, and patterns before machine learning modeling.
