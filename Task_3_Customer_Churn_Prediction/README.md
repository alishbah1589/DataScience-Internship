# Customer Churn Prediction

## Project Overview

This project predicts whether a bank customer is likely to leave the bank based on demographic and financial information.

## Dataset

Churn Modelling Dataset

## Objective

Identify customers who are likely to churn and understand the factors influencing customer retention.

## Features Used

* Credit Score
* Geography
* Gender
* Age
* Tenure
* Balance
* Number of Products
* Credit Card Status
* Active Membership
* Estimated Salary

## Target Variable

* Exited (0 = Stayed, 1 = Churned)

## Project Workflow

1. Data Loading
2. Data Cleaning
3. Feature Encoding
4. Train-Test Split
5. Random Forest Classification
6. Model Evaluation
7. Feature Importance Analysis

## Key Findings

Top factors influencing churn:

1. Age
2. Estimated Salary
3. Credit Score
4. Balance
5. Number of Products

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Conclusion

Machine learning can effectively identify customers at risk of leaving the bank and help businesses develop targeted retention strategies.
