# Personal Loan Acceptance Prediction

## Project Overview

This project predicts whether a customer is likely to accept a personal loan offer based on demographic and financial information. A Decision Tree Classifier was used to identify patterns in customer behavior.

## Dataset

Bank Marketing Dataset

## Objective

Identify customers who are more likely to accept personal loan offers and extract business insights that can support marketing campaigns.

## Features Used

* Age
* Job
* Marital Status
* Education
* Balance
* Housing Loan Status
* Personal Loan Status
* Contact Type
* Campaign Information
* Previous Marketing Outcomes

## Target Variable

* Loan Acceptance (y)

## Project Workflow

1. Data Loading
2. Data Exploration
3. Data Cleaning
4. Categorical Feature Encoding
5. Exploratory Data Analysis (EDA)
6. Model Training
7. Model Evaluation
8. Business Insight Extraction

## Visualizations

* Age Distribution
* Job Category Analysis
* Marital Status Distribution

## Machine Learning Model

* Decision Tree Classifier

## Evaluation Metric

* Accuracy Score

## Key Findings

* Customer demographics influence loan acceptance decisions.
* Job type and marital status provide useful information for customer segmentation.
* Machine learning can help banks target customers who are more likely to accept loan offers.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Conclusion

The Decision Tree model was successfully used to predict customer loan acceptance behavior. The project demonstrates how predictive analytics can support more effective and data-driven marketing strategies.
