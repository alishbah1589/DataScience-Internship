# Insurance Claim Amount Prediction

## Project Overview

This project focuses on predicting medical insurance claim amounts using personal and health-related information. A Linear Regression model was used to estimate insurance charges based on customer characteristics.

## Dataset

Medical Cost Personal Dataset

## Objective

Predict insurance claim amounts and understand how factors such as age, BMI, and smoking status affect medical insurance costs.

## Features Used

* Age
* Sex
* BMI
* Children
* Smoker Status
* Region

## Target Variable

* Charges

## Project Workflow

1. Data Loading
2. Data Inspection
3. Data Cleaning
4. Feature Encoding
5. Exploratory Data Analysis (EDA)
6. Linear Regression Model Training
7. Model Evaluation
8. Results Interpretation

## Visualizations

* Age vs Charges
* BMI vs Charges
* Smoking Status vs Charges

## Machine Learning Model

* Linear Regression

## Evaluation Metrics

* Mean Absolute Error (MAE)
* Root Mean Squared Error (RMSE)

## Key Findings

* Smoking status has a significant impact on insurance charges.
* Higher BMI values generally lead to higher insurance costs.
* Age is positively correlated with insurance claim amounts.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Conclusion

The Linear Regression model successfully predicted insurance claim amounts and highlighted the major factors influencing healthcare costs. The project demonstrates the practical application of regression techniques in the insurance industry.
